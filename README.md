# SQL Mastery

## Module Overview

SQL (Structured Query Language) is the standard language used to communicate with relational databases. Every backend developer must understand SQL before learning Spring Data JPA or Hibernate.

This module teaches SQL from beginner to intermediate level with practical examples using MySQL.

---

## Prerequisites

- Basic computer knowledge
- No database experience required

---

## Learning Outcomes

After completing this module, you will be able to:

- Design relational databases
- Create databases and tables
- Insert, update and delete records
- Write complex SQL queries
- Perform joins and subqueries
- Work with transactions
- Understand indexes and normalization
- Build a small database project
- Crack SQL interview questions
